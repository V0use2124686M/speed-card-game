# スピード（Speed）

スマホのブラウザで遊べる、2人対戦トランプ「スピード」。対戦相手は CPU で、難易度は3段階。
小学生が遊ぶ前提で、画面の文言は**小学3年生までの配当漢字**＋かな（それ以外の漢字は使わない）。音・記録・ひと休み機能つき。
ビルド不要の素の HTML/CSS/JS（依存パッケージなし）。PWA なのでホーム画面に追加してオフラインでも遊べる。

## 遊ぶ

`index.html` をブラウザで開くだけ。ローカルサーバーで見る場合:

```bash
python -m http.server 8123
```

スマホで遊ぶなら、このフォルダを GitHub Pages などの静的ホスティングに置くのが手軽。
https で配信すると Service Worker が有効になり、「ホーム画面に追加」でアプリのように起動できる

Service Worker はネットワーク優先で、圏外のときだけキャッシュを使う。

## ルール（公式ルール）

- 52枚を色で二分し、プレイヤーは赤（♥♦）26枚、CPU は黒（♠♣）26枚を使う。
- 手札4枚、山札22枚。場（台札）は左右2つで、開始時に両者が1枚ずつ出す。
- 台札の一番上と**数字が1つ違い**の手札を出せる。**A と K はつながる**（…Q-K-A-2-3…）。
- **同じ数字は出せない**（8 の上に 8 は不可）。手札に同じ数字が並んでも**重ねられない**。
  どちらも「出せる」とするのはハウスルールで、標準ルールでは認められていない。
- 出したらすぐ山札から手札を4枚に補充。手番はなく早い者勝ち。
- 両者とも出せる札がなくなったら、「せーの！」の5秒カウントダウン（5→1）のあと、両者が山札から1枚ずつ台札に出して再開。
  **カウントダウン中と開始前の「せーの！」の間はタイマーを止める**（待ち時間はタイムに含めない）。
  **どちらかの山札が尽きていたら、その「せーの」で終了して残り枚数の少ない方の勝ち**（下記）。
- 手札と山札を先に全部なくした方の勝ち。決着すると結果画面に切り替わる。

### 実装上の取り決め（公式ルールが定めていない部分）

- **手詰まり（せーの）の時点でどちらかの山札が尽きていたら、そこで終了。残り枚数の少ない方の勝ち**
  （同数なら引き分け）。結果画面に「二人とも 出せなく なりました」と理由を表示する。
  山札が尽きた側（手札4枚以下）は台札が変わるのを待つだけになり、続けても結果がほぼ変わらないため
  （2026-09-23 変更。以前は山札が残っている側が左右2枚出して続行していた）。
- 以前は台札の札を持ち主に戻して続行していたが、残り1枚まで来た側の札が増えてしまい
  分かりにくいため 2026-08-26 に廃止した。

## 操作

- 手札をタップして選び、出したい台札（左か右）をタップして出す。左右は必ず自分で選ぶ。
- 台札を先にタップすると、そこに出せる手札を自動で選んで出す。
- 出せない台札をタップしても選択は解除されないので、そのまま反対側をタップできる。
- 「せーの！」のカウントダウンが始まったとき、手札を選んでいなければ**一番左の手札を自動で選ぶ**
  （札が出た瞬間に台札を1タップするだけで出せる）。5秒の間に選び直せる。
- ゲーム中にアプリを離れる（タブを切り替える）と自動で中断し、戻ったら「つづける」で再開できる。

## 難易度

プレイヤーの操作が「手札を選ぶ → 台札を選ぶ」の2タッチなので、CPU はその分ゆるめに設定してある。

| | CPU の反応速度 | 見落とし率 | 置き場の選び方 |
|---|---|---|---|
| やさしい | 2.6〜4.0秒（※） | 60% | ランダム |
| ふつう | 1.4〜2.2秒 | 35% | ランダム |
| むずかしい | 0.7〜1.1秒 | 15% | 次に続きやすい方を選ぶ |

※ やさしいのみ、**自分が出すことも引くこともできない間は 0.45〜0.75秒**に短縮し、見落としもしない。
CPU の番を眺めるだけの時間が長くなりすぎるのを防ぐため。

## タイトル画面のオプション（難易度とは独立）

| 項目 | 選択肢 | 既定 |
|---|---|---|
| あなたの ふだ | 赤（♥♦）/ 黒（♠♣） | 赤 |
| 山ふだ | なし / あり（下記「山札ありモード」） | なし |
| ヒント | なし / あり（出せる手札が緑の枠で光る） | なし |
| 音 | なし / あり（効果音とバイブ） | あり |

選択内容と記録は localStorage（キー `speed-card-game/v1`）に保存され、次回起動時に復元される。
タイトル右下の「きろくを けす」で記録だけを全消去できる（設定は残る）。
タイトル左下にバージョンを表示する。**中身を変えたら `game.js` の `APP_VERSION` を上げること**
（更新が端末に届いているかを画面で確認するため）。

## ひと休み（中断・再開）

- HUD 左の「||」でいつでも中断。画面を離れた（タブ切り替え・通知）ときも自動で中断する。
- 中断中はタイマーが止まり、カードも操作できない。「つづける」で止まった時点から再開する。
- 「やめて はじめの画面へ」でタイトルに戻る。誤タップでいきなりゲームが消えないよう、
  やめる操作は必ずこの確認を挟む。

## 山札ありモード

タイトルで「やまふだ あり」にすると、**出した分の手札は減ったまま**になり、手札の横に出る山札を
タップして 1タップ 1枚ずつ補充する。1枚出すごとに 1タップ増えるぶん難しくなる。
CPU も同じルールで、出せないときは 1手番かけて自分で引く（片方だけ有利にならないようにするため）。

手詰まり判定も「出せない かつ 引けない」ときだけ働くので、引けるうちは「せーの！」にならない。

## 記録

難易度ごとに **ベストタイム / 勝ったときの相手の最大残り枚数 / 勝ち数 / 連勝数 / 最高連勝数** を保存し、
タイトル画面の**つよさボタンの右**にベストタイムと相手の残り枚数を表示する。結果画面には
「いままでで 一番 速い！」「いままでで 一番 大きな 差！」や連勝数を出す。
相手の残り枚数はタイムとは独立した記録で、多いほど大差での勝ち。
山札ありは別ゲームなので記録も別扱い（キーは `normal+draw` のようになる）。

## 文言のきまり

画面に出る文字は **小学1〜3年で習う漢字だけ**を使い、それ以外はかなで書く
（例: 「相手」「勝ち」「秒」「場のふだ」は漢字、「残り」「連勝」「山札」の札・残・連は4年以上なので
「のこり」「◯回 つづけて」「山ふだ」と書く）。文言を足すときはこの方針に合わせること。

## 音

効果音は Web Audio API で生成（音声ファイルなし）。カードを出す・出せない・カウントダウン・
場に出る・勝ち・負けで鳴り分ける。対応端末では `navigator.vibrate` でバイブも鳴らす。
AudioContext は「はじめる」を押したとき（ユーザー操作時）に初めて作る。
