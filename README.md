# スピード（Speed）

スマホのブラウザで遊べる、2人対戦トランプ「スピード」。対戦相手は CPU で、難易度は3段階。
ビルド不要の素の HTML/CSS/JS（依存パッケージなし）。

## 遊ぶ

`index.html` をブラウザで開くだけ。ローカルサーバーで見る場合:

```bash
python -m http.server 8123
```

スマホで遊ぶなら、このフォルダを GitHub Pages などの静的ホスティングに置くのが手軽。

## ルール（公式ルール）

- 52枚を色で二分し、プレイヤーは赤（♥♦）26枚、CPU は黒（♠♣）26枚を使う。
- 手札4枚、山札22枚。場（台札）は左右2つで、開始時に両者が1枚ずつ出す。
- 台札の一番上と**数字が1つ違い**の手札を出せる。**A と K はつながる**（…Q-K-A-2-3…）。
- 出したらすぐ山札から手札を4枚に補充。手番はなく早い者勝ち。
- 両者とも出せる札がなくなったら、「せーの！」の5秒の溜めのあと、両者が山札から1枚ずつ台札に出して再開。
  山札が尽きている側は出さない（片方の台札だけ更新される）。
- 手札と山札を先に全部なくした方の勝ち。

### 実装上の取り決め（公式ルールが定めていない部分）

- 両者の山札が尽きて手詰まりになったら、台札の下に埋まっている札を持ち主の色ごとに回収・
  シャッフルして山札に戻し、再開する。
- それを繰り返しても誰も1枚も出せない場合は、残り枚数の少ない方の勝ち（同数なら引き分け）。

## 操作

- 手札をタップして選び、出したい台札（左か右）をタップして出す。左右は必ず自分で選ぶ。
- 台札を先にタップすると、そこに出せる手札を自動で選んで出す。
- 出せない台札をタップしても選択は解除されないので、そのまま反対側をタップできる。
- ゲーム中にアプリを離れる（タブを切り替える）と中断扱いになる。

## 難易度

| | CPU の反応速度 | 見落とし率 | 置き場の選び方 |
|---|---|---|---|
| やさしい | 1.0〜1.7秒 | 40% | ランダム |
| ふつう | 0.5〜0.9秒 | 15% | ランダム |
| むずかしい | 0.23〜0.4秒 | 2% | 次に続きやすい方を選ぶ |

## 補助（難易度とは独立、デフォルトは「なし」）

「あり」にすると、出せる手札が緑の枠で光る。難易度とは別にタイトル画面で選ぶ。
